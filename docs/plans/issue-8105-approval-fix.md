## 调查与验证记录

### 已确认的问题

- 快速审批在工具开始等待前就移除待审批记录，原先按 ID 查询会丢失决定。
  回归测试覆盖真实治理工具调用；现在消费者保留请求对象并读取同一个决定。
- 直接等待共享 Future 会在超时时取消 Future；现在使用 `asyncio.shield`，
  超时明确返回 TIMEOUT，取消单个等待者也不会影响其他等待者。
- 点击审批与超时/其他决定并发时，接口可能错误确认成功或访问空结果。
  现在到期请求只能超时拒绝，失去竞争的操作返回 HTTP 409。
- 信封按钮能进入收件箱，但先前保留在消息页签，未直接展示待审批内容。
  有待审批请求时，现在进入 `/inbox?tab=approvals`，兼容侧栏展开和收起状态。
- 前端遇到 `success: false` 的审批响应时现在会报告失败。
